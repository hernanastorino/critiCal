Política de privacidad de critiCal

critiCal es una aplicación de uso personal de un único usuario, su autor. No está abierta al público.

Datos a los que accede

Con tu autorización, critiCal lee los eventos de tus calendarios de Google para planificar tiempo de estudio y escribe bloques planificados en un calendario dedicado ("📚 Plan").

Uso y almacenamiento

  • Los datos se usan únicamente para calcular y mostrar tu planificación.
  • Se guardan en una base de datos privada (Supabase), protegida por seguridad a nivel de fila; solo tu cuenta puede leerlos.
  • Los tokens de acceso se almacenan cifrados.
  • No se venden, comparten ni transfieren datos a terceros, ni se usan para publicidad o para entrenar modelos de IA.

El uso de la información recibida de las APIs de Google cumple con la Google API Services User Data Policy, incluidos los requisitos de uso limitado.

Eliminación

Podés revocar el acceso en cualquier momento desde myaccount.google.com/permissions. Al eliminar la cuenta en critiCal se borran todos los datos asociados.
